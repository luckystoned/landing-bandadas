# Decisiones

- Mantener Astro, TypeScript, Tailwind 3 y salida estática.
- No incorporar React, backend ni formulario propio.
- Usar HTML real para el hero y CSS para recursos decorativos.
- Centralizar contenido y enlaces en `src/content/bandadas.ts`.
- Usar GES como caso propio en curso.
- Mostrar los demás premios solo como referentes independientes.
- Preparar tracking desacoplado de cualquier proveedor.
- Mantener `bandadas.com` como canonical.
