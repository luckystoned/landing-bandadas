# Sistema visual

La identidad traduce la presentación DIXB_02 a una interfaz web editorial: alto contraste, tipografía sans de gran escala, grillas precisas y geometrías modulares.

## Paleta

- Ink `#090909`
- Canvas `#F2F2F0`
- Electric `#164FDC`
- Pink `#F28AB8`
- Orange `#F04416`

## Principios

- El contenido y la jerarquía sostienen el impacto.
- Los bloques de color marcan cambios narrativos.
- Las geometrías se resuelven con CSS/SVG liviano.
- Las fotografías se reservan para casos propios o material autorizado.
- La experiencia es mobile first y limita anchos de lectura.
- Toda interacción respeta teclado, foco y `prefers-reduced-motion`.
